# ADR-018: Lab database binds to port 5433, not 5432

**Status**: Accepted · **Re-verified**: 2026-08-23 — still true, unchanged
**Date**: 2026-08-21
**Decided by**: Lab foundation increment (001-lab-foundation-bootstrap), acting on P0 plan §10
**Evidence**: specs/001-lab-foundation-bootstrap/research.md — environment re-measurement, 2026-08-20

## Context

The P0 plan's default for a local PostgreSQL would be the conventional port 5432. On the target
machine that port is **already held**:

- Measured 2026-08-20 (and re-confirmed 2026-08-21): `postgres` PID 1984,
  `/opt/homebrew/opt/postgresql@14/bin/postgres`, listening on `127.0.0.1:5432` and `[::1]:5432`.
- That instance is `postgresql@14`, a Homebrew service **serving other projects on this machine**.
  It is untouchable: stopping it, reconfiguring it, or upgrading it is out of scope and would break
  those projects.

Port 5433 was measured **free** on the same date.

## Decision

The Lab database container publishes **127.0.0.1:5433 → container 5432**. All Lab connection
configuration (`LAB_DB_PORT`) uses 5433.

## Consequences

- The Lab database and `postgresql@14` coexist without conflict; verification asserts the neighbour
  is still listening on 5432 after every run (SC-008).
- Every later phase, script, and runbook must treat **5433** as the Lab database port and never
  attempt to claim 5432.
- The bind is loopback-only (FR-018); the port choice does not change the exposure model.

## Re-verification 2026-08-23

`lsof` confirms `postgresql@14` still on `127.0.0.1:5432` and the Lab container on
`127.0.0.1:5433`. Server reports `17.11 (Debian 17.11-1.pgdg12+2)`, database `injazedu_lab`,
**8,398 kB**, 12 tables. Nothing in this ADR has drifted.

## Alternatives considered

- **Reuse the existing postgresql@14 instance** — rejected: wrong major version (the Lab requires
  PostgreSQL 17 with pgvector 0.8.6), and sharing a production-adjacent service with the Lab
  violates the isolation the Lab exists to provide.
- **Stop/reconfigure postgresql@14** — rejected: it serves other projects; the constitution's
  scope principle forbids breaking them.
